# PoLingvo — «Что от меня хотят?»

English version: [README.md](README.md)

PoLingvo объясняет израильские официальные письма (ирия, битуах леуми, банк,
купат холим, хеврат хашмаль…) русскоязычным олим. Загрузите фото или PDF
письма на иврите — получите понятную карточку по-русски: кто прислал, что
требуют, сумма, срок, что будет при игнорировании и что делать (бытовые шаги).

Проект для конкурса **XPRIZE «Build with Gemini»** (категория Professional
Services).

## Как это работает

```
фото/PDF ──► Проход A (Gemini, structured output, T=0) — извлечение черновика
         ──► Проход B (Gemini-критик, T=0)             — проверка отправителя/суммы/срока
         ──► политика решения                          — карточка или честный отказ
         ──► value locking                             — числа и даты только из
                                                          верифицированного JSON
         ──► санитайзер выхода                         — никаких юрсоветов
```

Ключевые свойства закреплены **в коде**, а не только в промптах:

- **Честный отказ.** Если два прохода расходятся по сумме или сроку, или
  уверенность низкая — ответ «покажите письмо человеку», а не догадка.
  Отказ не списывает платный кредит.
- **Value locking.** Каждое число и дата в карточке — из верифицированного
  JSON. Свободный текст сканируется; чужое число → одна перегенерация с
  замороженными константами в XML-тегах, при повторе → отказ.
- **Граница продукта.** PoLingvo объясняет письма и подсказывает бытовые шаги
  («куда пойти, куда позвонить»). Никогда не составляет обращения/ерурим и не
  даёт юридических советов — на выходе кодовый стоп-лист.
- **Приватность архитектурно.** Письма обрабатываются только в памяти запроса:
  ни диска, ни бакетов, ни temp-файлов. Логи проходят PII-маскер (ת"ז с
  проверкой чек-суммы, телефоны, email). Firestore хранит только кредиты,
  покупки (хеш email), анонимные метрики и события гроссбуха.
- **Устойчивость к prompt-injection.** Содержимое письма помечено как
  недоверенные данные в каждом system prompt; есть e2e-тест с инъекцией.

## Стек

FastAPI (Python 3.12) · Gemini API (`google-genai`, structured output) ·
Cloud Run (me-west1) · Firestore · Stripe Payment Link · одна HTML-страница на
vanilla JS (mobile-first, RTL для цитат на иврите).

## Локальный запуск

```bash
pip install -r requirements-dev.txt
export GEMINI_API_KEY=...        # локально работает in-memory хранилище
uvicorn app.main:app --reload
# открыть http://localhost:8000
```

Тесты:

```bash
pytest                       # юнит- и API-тесты (без сети)
pytest -m golden             # golden-set гейт (нужен API-ключ и data/golden)
python scripts/run_golden.py # гейт + запись в docs/eval_log.md
```

## Деплой

Пуш тега `v*` → GitHub Actions собирает и деплоит на Cloud Run
(`.github/workflows/deploy.yml`). Конфигурация — env-переменные
(`.env.example`), секреты — в GCP Secret Manager.

## Гейт качества

Релиз требует порогов golden-set (deadline ≥14/15, amount ≥14/15,
sender ≥13/15, оба негативных → отказ, тесты инъекции/санитайзера/value
locking зелёные). Каждый прогон — в [docs/eval_log.md](docs/eval_log.md).
Гроссбух выручки: [docs/ledger.md](docs/ledger.md).
